# Brand assets — what to replace

Two brand elements are **placeholders** because the official assets could not be reached
from the build environment (`fdgyms.com` is blocked by its network policy). Both are
isolated to a single place so swapping them is a small job.

## 1. The logo

The header and footer currently use a CSS/text lockup: an `FD` monogram box plus the
words *Fitness Depot / Columbia, MS*.

**To use the official logo**, replace the markup in `index.html` — it appears twice, in
`<header class="header">` and in `<footer class="footer">`, both marked with a comment:

```html
<a class="logo" href="#top" aria-label="Fitness Depot Columbia — home">
  <img src="assets/img/logo-fitness-depot.svg"
       alt="Fitness Depot Columbia"
       width="200" height="44">
</a>
```

Prefer an **SVG**. The header sits on white and the footer on near-black, so you need
either a logo that works on both, or two files (add a second `<img>` and swap by section).
The `.logo__loc` line ("COLUMBIA, MS") is worth keeping under a wordmark — it reinforces
the location on every screen.

`assets/favicon/favicon.svg` and `assets/favicon/apple-touch-icon.png` are also
placeholders built from the same monogram. Replace them with the real mark.

## 2. The colour palette

**The exact Fitness Depot brand colours could not be verified**, so the palette is a
calibrated stand-in: near-black, white, steel grey, and a strong red accent, chosen to
match the industrial "Depot" feel described in the brief.

All six brand values live at the top of `assets/css/styles.css`:

```css
:root {
  --fd-red:      #e01b22;   /* primary accent — buttons, rules, highlights */
  --fd-red-dark: #b3141a;   /* hover state */
  --fd-red-glow: rgba(224, 27, 34, 0.35);  /* glows and shadows */
  --fd-ink:      #0c0e12;   /* primary dark surface */
  --fd-ink-2:    #141922;   /* raised dark surface (cards on dark) */
  --fd-ink-3:    #1e2530;   /* borders/edges on dark */
}
```

Change those values and the entire site follows — nothing else references a brand colour
directly. Keep `--fd-red-glow` as the same red in `rgba()` form.

Two things to preserve when swapping in the real red:

- **Contrast.** White text on `--fd-red` must stay readable (the current red gives about
  4.6:1). If the official red is lighter, use dark text on red buttons instead.
- **Restraint.** Red is used as an accent — CTAs, rules, icons, the featured plan. Its
  impact comes from being surrounded by black and white, not from covering more area.

The placeholder images also embed the red (`#e01b22`) and dark (`#0c0e12`); they are
regenerated by `tools/make-placeholders.sh` if you want them to match a new palette, but
they disappear as real photos arrive.

## 3. Typography

Headings use **Barlow Condensed** (bold, condensed, uppercase) and body copy uses
**Inter**, both loaded from Google Fonts in the `<head>`. They were chosen to read as
strong and modern without being a novelty gym font.

If Fitness Depot has an official typeface, replace the two font URLs and update
`--display` / `--body` in `:root`. Keep a real fallback stack: the display fallback is
`'Arial Narrow', Arial` — a condensed fallback matters, because a wide fallback changes
how much space the headlines take.
